牛马待办隐私政策

生效日期：2026-10-23

牛马待办不要求账号，不提供云同步，也不会出售用户数据或将其用于广告。

保存在本设备的数据

任务标题、完成状态、任务位置、物资、称号、设置、语录历史以及本地统计队列保存在浏览器的 chrome.storage.local。任务标题永不上传。插件不读取网页、不使用内容脚本，也不采集浏览器指纹。

可选的匿名统计

匿名统计默认处于未选择状态，并且不会开始。只有你主动选择“允许匿名统计”后，插件才可能发送随机安装标识、事件类型、事件时间、扩展版本、任务位置、物资编号、当日完成数、等级变化、有限的匿名错误码和有限时长。这些事件用于了解插件打开、任务完成、留存、等级进度和匿名错误，不用于广告。

发送内容不包含任务标题、备注、网页内容、联系人、姓名或精确个人信息。统计服务使用 Cloudflare Workers 托管，数据保存在 Cloudflare D1。Worker 不保存来源 IP 地址。

数据保留

原始统计事件保留 90 天后删除。不得用于识别个人的汇总结果可能保留更久。统计服务的数据只发送给 Cloudflare，作为托管和数据库服务提供方。

你的选择

你可以随时在设置中关闭匿名统计。关闭后不再新增事件，并删除尚未发送的本地队列和安装标识。选择“清除本地数据”会删除任务、物资、等级、设置、语录历史、安装标识和统计队列。

数据出售与广告

牛马待办不出售、不出租用户数据，不使用用户数据投放广告，也不将匿名统计用于信用、保险、贷款或其他与插件功能无关的用途。

Chrome Web Store 有限使用

牛马待办对用户数据的使用仅限提供和维护本扩展的单一用途：本地每日待办、奖励与可选匿名统计。我们不会将用户数据用于个性化广告、信用评估或贷款目的，也不会出售用户数据。除本政策说明的 Cloudflare（仅作为匿名统计的托管和数据库服务提供方）外，不向第三方转移用户数据。除为提供或改进该单一用途、保障安全或遵守法律所必需的情况外，不允许人工读取用户数据。

Niuma Todo Privacy Policy

Effective date: 2026-10-23

Niuma Todo requires no account, offers no cloud sync, and never sells personal data or uses it for advertising.

Data stored on your device

Task titles, completion state, task positions, materials, titles, settings, quote history, and the local analytics queue are stored in chrome.storage.local. Task titles are never uploaded. Niuma Todo does not read web pages, does not use content scripts, and does not collect browser fingerprints.

Optional anonymous analytics

Analytics is undecided and disabled by default. It begins only after you select “Allow anonymous analytics.” If allowed, Niuma Todo may send a random installation identifier, event type, event time, extension version, task position, material identifier, daily completion count, rank transition, a limited anonymous error code, and limited duration values. These events are used to understand extension opens, task completion, retention, rank progression, and anonymous failures. They are not used for advertising.

Task titles, notes, page content, contacts, names, and precise personal information are not included. The analytics service is hosted on Cloudflare Workers and stored in Cloudflare D1. The Worker does not store source IP addresses.

Retention

Raw analytics events are retained for 90 days and then deleted. Aggregate results that cannot identify an individual may be retained longer. Data is sent only to Cloudflare as the hosting and database provider for the analytics service.

Your choices

You can turn analytics off at any time in Settings. Turning it off stops new events and deletes the unsent local queue and installation identifier. Choosing “Clear local data” deletes tasks, inventory, ranks, settings, quote history, installation identifier, and the analytics queue from the extension.

No sale or advertising

Niuma Todo does not sell or rent user data, does not use user data for advertising, and does not use anonymous analytics for credit, insurance, lending, or any purpose unrelated to the extension.

Chrome Web Store Limited Use

Niuma Todo's use of user data is limited to providing and maintaining the extension's single purpose: a local daily task list, rewards, and optional anonymous analytics. We do not use user data for personalized advertising, creditworthiness, or lending, and we do not sell user data. We do not transfer user data to third parties except Cloudflare, which serves only as the hosting and database provider for anonymous analytics as described in this policy. Humans do not read user data except when necessary for the single purpose, security, or legal compliance.
